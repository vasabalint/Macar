1. Executive Summary & Problem Statement

In modern hospitality markets such as Baku, Azerbaijan, restaurants operate on narrow net margins (typically 5%–12%). Independent restaurateurs frequently grapple with disconnected manual workflows: food inventories tracked on physical clipboards, POS terminals unlinked to back-office supply data, shift scheduling organized in informal messaging chats, and menu pricing divorced from dynamic wholesale inflation.

Macar is an all-in-one, agile restaurant operations and analytics platform engineered to eliminate these operational blind spots. By integrating POS order execution directly with atomic recipe-level stock depletion, dynamic food-cost margin calculations, automated shift conflict detection, and an AI operational advisor, Macar provides hospitality managers with full visibility and control over their daily economics.

4. Section 4: DevOps & System Health Monitoring Rules

Rule 1 — API Latency Spike: Triggered when P95 response latency exceeds 1,500 ms for 2 minutes. Dispatches high-latency alert to the engineering channel.
Rule 2 — DB Connection Pool Saturation: Triggered when database connection pool utilization exceeds 85% for 3 continuous minutes.
Rule 3 — Server Error Rate (HTTP 5xx): Triggered when HTTP 5xx responses exceed 5% of total requests over a 5-minute sampling window.
Rule 4 — Zero-Sales Anomaly: Triggered when zero POS sales transactions are recorded for 30 consecutive minutes during active operational hours (12:00–22:00).
Rule 5 — Immediate Stock Depletion: Triggered when the available stock level of any critical ingredient drops to 0 units.

5. Technical Stack & Architecture

The platform is constructed with modern web standards prioritizing responsiveness, strict type safety, and agile maintenance:

  • Frontend: React 18 with TypeScript 5, Vite build engine, and Tailwind CSS.
  • Visualizations: Recharts 2.12 for fluid, interactive charts.
  • State & Storage: Reactive Observer Store with browser-level LocalStorage persistence.
  • AI Integration: Google Gemini 2.5 Flash API with local rule-based heuristic fallback.
  • Incident Dispatching: Telegram Bot API (HTTPS sendMessage) with sandbox simulation fallback.
